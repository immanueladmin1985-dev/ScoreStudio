# 새 기호를 넣는 도구

사용자 요청(2026-11-06, "그냥 해"): 가져오기만 되던 기호들을 Finale 도구처럼 넣고 지울 수 있게 한다. 모든 편집은 실행 취소·다시 실행이 된다. 키 기본값은 Finale 매뉴얼을 확인하지 못한 추정이므로 편집 > 단축키 설정에서 바꿀 수 있다(`docs/KEYS_AND_TOOLS.md`).

## 스마트 도형 도구 (시작 음표 → 끝 음표)
| 키 | 도형 | 만드는 것 |
|---|---|---|
| G | 글리산도 | `ScoreGlissando` (곧은 선, 글자 "gliss."). 쉼표에는 걸 수 없다. |
| T | 트릴 연장선 | `LineKind.TrillLine`. 시작 음표에 트릴(tr)이 없으면 함께 붙인다. |
| B | 괄호선 | `LineKind.Bracket`, 보표 위, 양 끝 갈고리 아래로 |
| P | 페달 선 | `LineKind.Pedal`, 선식, 보표 아래 |
| Shift+P | 페달(Ped. *) | `LineKind.Pedal`, 기호식, 보표 아래 |
- Delete: 고른 음표에서 시작하는 이음줄·크레셴도·글리산도·선을 모두 지운다.

## 표현 도구 (고른 음표 또는 입력 위치)
| 키 | 기호 |
|---|---|
| R | 리허설 마크: 앞 마크의 다음 글자(A → B …). 메뉴의 "리허설 마크 글자 넣기..."로 글자를 정할 수 있다. |
| S / C | 세뇨 / 코다 넣기·빼기 |

## 아티큘레이션 도구 (고른 화음)
| 키 | 기호 |
|---|---|
| N | 운지 번호 입력 창: 아래 음부터 띄어 쓴다("1 3 5"), 바꿔 짚기는 "4-1". 아래에 쓰기 선택 가능. 비우면 지운다. |
| 1·2·3 | 트레몰로 빗금 1·2·3개 (메뉴에 "빼기") |
| Z | 버즈 롤 넣기·빼기 |
| R | 아르페지오 넣기·빼기 (메뉴에 위·아래 화살표, 논아르페지오) |
| 메뉴 | 임시표 기호 ♯·♭·♮·빼기, 큐 음표로 바꾸기 |
- 메뉴에는 새 아티큘레이션(강세, 숨표, 재즈 기호, 슐라이퍼 등)도 이름대로 모두 나온다.

## 유틸리티 메뉴 (입력 위치의 마디)
- 큐 음표로 바꾸기·되돌리기: 고른 화음
- 4/4를 C, 2/2를 ¢로 쓰기·되돌리기: 그 마디부터 다음 박자 변경 전까지, 모든 파트 (Finale 박자표 대화상자의 "줄여 쓰기")
- 마디 끝 마디선의 페르마타: 그 마디의 모든 파트

## 수용 기준과 결과 (2026-11-06)
- 자동 테스트(`ScoreEditorMarksTests`): 도형 다섯 가지의 값, 트릴 연장선에 tr이 붙음, Delete로 지우기와 실행 취소, 리허설 마크 A → B와 글자 지정, 세뇨 넣기·빼기, 운지 번호(화음, 바꿔 짚기, 잘못된 입력 거절, 지우기), 트레몰로·버즈 롤·아르페지오·임시표 기호·큐 음표, C 박자표 켜기·끄기, 마디선 페르마타와 실행 취소. — 통과
- 단축키 표: 도구마다 키가 겹치지 않고, 모든 명령에 이름과 실행할 곳이 있다(`KeyMapTests`). — 통과
- 화면(WPF) 연결은 Windows CI 빌드로 확인하고, 실제 조작은 Windows에서 확인한다(`docs/WINDOWS_CHECKLIST.md`).
- 아직 없는 것: 다른 조표·3+2 박자표·박자 없음·이조 변경·코드 다이어그램·숫자 저음·지시 기호(symbol)를 넣는 도구, 장식음(꾸밈음) 입력.

## Speedy Entry: 빔·꾸밈음·숨기기 (스키마 28 → 29)
그동안 "아직 지원하지 않음"으로 흐리게 두었던 Finale Speedy Entry 명령 세 가지를 만들었다. 유틸리티 메뉴에도 있다.
| 키 | 명령 | 하는 일 |
|---|---|---|
| / | 빔 끊기·잇기 | 고른 음표가 빔 가운데 있으면 그 앞에서 끊고, 빔의 처음이거나 빔이 없으면 바로 앞 음표(8분음표보다 짧고 붙어 있는 음표)와 잇는다. 음표를 새로 넣으면 그 성부의 빔은 박 단위로 다시 묶인다. |
| ; | 꾸밈음으로 바꾸기 | 고른 음표(화음)를 같은 성부 다음 음표의 꾸밈음(빗금 있는 8분음표)으로 옮기고, 원래 자리는 같은 길이의 쉼표가 된다. 다음 음표가 없으면 거절한다. |
| O | 숨기기·보이기 | `ScoreEvent.Hidden`: 박자와 소리는 그대로, 화면과 인쇄에서 그리지 않는다. 숨긴 음표만으로 된 빔도 그리지 않는다. |

- 가져오기·내보내기: MusicXML `note print-object="no"`. Finale이 성부를 채우려고 넣는 숨긴 쉼표가 이제 보이지 않는다(공개 시험 파일 8개, `zwei_gesange`의 18개 포함).
- 결과(2026-11-06): 자동 테스트(빔 끊기·다시 잇기·앞과 잇기·실행 취소, 꾸밈음 바꾸기·실행 취소·다음 음표 없음 거절, 숨기기와 그리지 않음, 숨긴 쉼표 가져오기·내보내기) 통과. 내보낸 24개 파일 스키마 통과.
- 키 기본값(/ ; O)은 Finale Speedy Entry를 기억으로 따른 것이다. 다르면 단축키 설정에서 바꾼다.
